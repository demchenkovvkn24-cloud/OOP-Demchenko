Хід роботи

У проєкті IndependentWork2 реалізовано клас Product для обробки товарів в інтернет магазині.

Основні рішення в класі:

Поля та властивості: оголошено приватні поля для ідентифікатора, назви, ціни, категорії та кількості на складі.
Для всіх полів зроблено публічні read-only властивості без сетерів.

Основний конструктор: приймає всі 5 параметрів та повністю заповнює дані обєкта.

Скорочений конструктор: приймає лише id, назву та ціну. Передає ці значення в основний конструктор через this(...),
підставляючи за замовчуванням категорію Uncategorized та кількість 0.


Конструктор копіювання: приймає інший обєкт Product та копіює його дані через заклик основного конструктора.

Метод ToString: перевизначено для зручного виводу інформації про товар в один рядок із форматуванням ціни.

У методі Main створено три екземпляри класу за допомогою кожного з конструкторів та виведено їх у консоль.

Відповіді на контрольні запитання

1. Перевантаження конструкторів потрібне для того, щоб створювати обєкти з різним набором початкових даних залежно від ситуації.

2. Виклики через this(...) дозволяють уникнути дублювання коду та тримати всю логіку ініціалізації в одному місці.

3. Властивості тільки для читання захищають дані від випадкових змін після створення обєкта.

4. Перевизначення ToString спрощує вивід інформації та налагодження програми, оскільки обєкт можна одразу передавати в консоль.

Висновок

Під час виконання роботи опрацьовано перевантаження конструкторів у C#, виклик одного конструктора з іншого через this(...),
створення незмінних властивостей та перевизначення методом ToString для форматованого виводу даних.
