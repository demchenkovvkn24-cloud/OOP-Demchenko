Хід роботи

У проєкті lab5v6 реалізовано клас IntStack (Варіант 6) для роботи зі стеком цілих чисел.

Основні рішення в класі:

Приватний список `_items` для зберігання елементів, а також методи `Push`, `Pop`, `Peek` і властивість `Count`.

Індексатор `this[int index]` з перевіркою виходу за межі списку для читання та зміни елементів за індексом.

Перевантажений оператор `+` для об'єднання елементів двох стеків у новий, а також оператори `==` та `!=` для порівняння вмісту (із підтримкою nullable-типів).

Перевизначено методи `ToString` для форматованого виводу, `Equals` та `GetHashCode` для коректного порівняння об'єктів.

У методі `Main` перевірено роботу індексатора, додавання стеків та їх порівняння.

Відповіді на контрольні запитання

1. Індексатор дозволяє звертатися до елементів об'єкта через квадратні дужки `obj[index]`, як до масиву.

2. Властивість має власне ім'я і викликається через крапку, а індексатор оголошується через `this` і приймає параметр у квадратних дужках.

3. Можна перевантажувати арифметичні (`+`, `-`), побітові, а також оператори порівняння (`==`, `!=`, `<`, `>`).

4. Перевизначення `Equals` і `GetHashCode` потрібне, щоб об'єкти з однаковеним вмістом коректно порівнювалися та працювали в колекціях.

5. Індексатори роблять синтаксис простішим, усуваючи потребу викликати додаткові методи для доступу до елементів.

Висновок

Під час виконання роботи реалізовано клас з індексатором та перевантаженими операторами, а також перевизначено методи `ToString`, `Equals` та `GetHashCode` для роботи з об'єктами.
