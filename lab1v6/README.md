ЗВІТ з лабораторної роботи №1
Тема: Створення першого проєкту. Класи, об'єкти, конструктори та деструктори
Варіант: №6 (BankAccount)

Хід роботи
У проєкті lab1v6 реалізовано клас BankAccount за варіантом №6. У класі додано приватні поля owner і accountNumber,
публічну властивість Balance з геттером і сеттером, конструктор для ініціалізації об'єкта, а також методи Deposit() і Withdraw().

У методі Main створено та перевірено 3 об'єкти класу BankAccount, виконано виклики методів Deposit() та
Withdraw() і виведено результати операцій у консоль. Для проєкту налаштовано файл .gitignore та завантажено код у віддалений репозиторій GitHub.

Висновок
Ознайомився із середовищем розробки Visual Studio Code та .NET SDK. Навчився створювати класи, об'єкти,
використовувати інкапсуляцію через приватні поля та публічні властивості, а також працювати з конструкторами
та методами у C#. Опанував налаштування .gitignore та публікацію проєкту на GitHub.

Відповіді на контрольні запитання

1. Що таке клас та об'єкт? Яка між ними різниця? — Клас це шаблон (опис полів та поведінки),
а об'єкт це конкретний екземпляр цього класу, створений у пам'яті через new.

2. Для чого використовуються конструктори? Чи може клас існувати без них? — Конструктори потрібні для початкової
ініціалізації об'єкта. Клас може існувати без явного конструктора, тоді C# автоматично створює стандартний конструктор без параметрів.

3. Чим відрізняється приватне поле від публічної властивості? Навіщо потрібна інкапсуляція? — Приватне поле доступне тільки всередині класу,
а публічна властивість надає контрольований доступ до нього ззовні. Інкапсуляція потрібна для приховування деталей реалізації та захисту даних від некоректних змін.
