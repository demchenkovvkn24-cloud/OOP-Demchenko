Виконання завдання У VS Code створив проєкт на C# за варіантом №6 (клас BankAccount). 
Реалізував приватні поля (_owner, _accountNumber, _balance), властивості, основний
конструктор і додатковий через : this(), методи Deposit та Withdraw, а також деструктор.
У Main створив об'єкти, перевірив методи і запустив GC.Collect() для демонстрації роботи збирача сміття.

Висновок Навчився використовувати перевантаження конструкторів і ланцюговий виклик : this()
для уникнення дублювання коду. Розібрався з життєвим циклом об'єкта та роботою Garbage Collector у C#.

Відповіді на контрольні запитання

1.Це створення кількох конструкторів з різними параметрами, що дозволяє гнучко ініціалізувати об'єкти.

2.Один конструктор передає дані іншому в тому ж класі, щоб не повторювати код перевірок і присвоєнь.

3.Збирач сміття (GC), коли на об'єкт більше немає активних посилань в програмі.

4.Це знижує продуктивність і призупиняє програму, а GC краще сам знає момент для очищення.
