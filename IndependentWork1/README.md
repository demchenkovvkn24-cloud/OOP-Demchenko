Хід роботи

У проєкті IndependentWork1 було створено три класи: Car, Student та Book.

Реалізований функціонал класів:

Car: містить приватні поля _brand та _fuel, властивість Brand з get/set та read-only властивість Fuel (лише get). 
Метод CanDrive(double distance) перевіряє, чи вистачить пального для подолання вказаної відстані.

Student: містить поля _name та _averageGrade, властивість Name та конструктор. Метод IsExcellent() перевіряє, чи є студент відмінником (середній бал не менше 90).

Book: містить поля _title та _pages, властивість Title та конструктор. Метод ReadingTime() вираховує орієнтовний час читання книги у хвилинах.

Тестування у методі Main:

Створено об'єкти кожного класу через конструктори.

Викликано методи класів та виведено результати їхньої роботи в консоль.

Відповіді на контрольні запитання

1. Які мінімальні елементи повинен містити клас у цьому завданні?
Мінімум 2 приватних поля, 1 публічну властивість (зокрема read-only), конструктор та 1 метод з обчисленням або перевіркою стану.

2. Чому поля доцільно робити приватними, а доступ надавати через властивості?
Це інкапсуляція. Приватні поля захищають дані від прямого некоректного редагування ззовні, а властивості надають контрольований доступ (дозволяють створити поле тільки для читання чи додати перевірку).

3. Для чого в класі потрібен конструктор і як він пов'язаний зі станом об'єкта?
Конструктор викликається при створенні об'єкта та ініціалізує його приватні поля, задаючи початковий стан об'єкта.

4. Як у Main показати, що методи класу працюють коректно?
Створити екземпляр класу через конструктор, викликати його методи та вивести результати у консоль.

Висновок

На цій роботі було розглянуто базовий синтаксис C# для оголошення класів, використання приватних полів та властивостей (зокрема read-only) для підтримки інкапсуляції,
ініціалізацію об'єктів через конструктори та реалізацію методів обробки даних.
